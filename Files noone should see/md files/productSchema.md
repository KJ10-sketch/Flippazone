# 🛍️ Product Schema

This schema defines the complete structure for product documents in the Flippazone e‑commerce database.

---

## 📋 Complete Schema Fields

| Field Name | Type | Constraints / Description |
| :--- | :--- | :--- |
| `_id` | ObjectId | Auto‑generated by MongoDB |
| `name` | String | ✅ Required, trimmed |
| `description` | String | ✅ Required |
| `price` | Number | ✅ Required, min: `0` |
| `discountPrice` | Number | ⭕ Optional, min: `0` |
| `countInStock` | Number | ✅ Required, default: `0` |
| `sku` | String | ✅ Required, unique |
| `category` | String | ✅ Required |
| `brand` | String | ⭕ Optional |
| `sizes` | [String] | ✅ Required, enum: `['XS','S','M','L','XL','XXL']` |
| `colors` | [String] | ✅ Required |
| `collections` | String | ✅ Required |
| `material` | String | ⭕ Optional |
| `gender` | String | Enum: `['Men','Women','Unisex']` |
| `images` | Array of Objects | ✅ Required |
| ↳ `url` | String | ✅ Required (inside `images`) |
| ↳ `altText` | String | ⭕ Optional (inside `images`) |
| `rating` | Number | Default: `0`, min: `0`, max: `5` |
| `numReviews` | Number | Default: `0`, min: `0` |
| `tags` | [String] | ⭕ Optional |
| `user` | ObjectId | ✅ Required, ref: `User` |
| `metaTitle` | String | ⭕ Optional (SEO) |
| `metaDescription` | String | ⭕ Optional (SEO) |
| `metaKeywords` | String | ⭕ Optional (SEO) |
| `dimensions` | Object | ⭕ Optional |
| ↳ `length` | Number | (inside `dimensions`) |
| ↳ `width` | Number | (inside `dimensions`) |
| ↳ `height` | Number | (inside `dimensions`) |
| `isFeatured` | Boolean | Default: `false` |
| `isPublished` | Boolean | Default: `false` |
| `createdAt` | Date | Auto‑generated by timestamps |
| `updatedAt` | Date | Auto‑updated by timestamps |

---

## 🧠 Schema Notes

- **`rating`** and **`numReviews`** track customer feedback – used for average rating display.
- **`tags`** are optional but improve search and filtering (e.g., `["new", "sale", "trending"]`).
- **`user`** references the `User` who created the product – **required** for admin/owner tracking.
- **`metaTitle`**, **`metaDescription`**, and **`metaKeywords`** are for SEO optimization.
- **`dimensions`** stores product measurements (length, width, height) – optional.
- **`sku`** is unique for inventory tracking.
- **`images`** stores multiple product images with optional alt text for accessibility.
- **`gender`** restricts values to Men, Women, or Unisex.
- **`isFeatured`** and **`isPublished`** control visibility without deleting products.

## 💻 Mongoose Schema Implementation

```javascript
const mongoose = require("mongoose");

const productSchema = new mongoose.Schema(
    {
        // ── Basic Info ──
        name: {
            type: String,
            required: true,
            trim: true,
        },
        description: {
            type: String,
            required: true,
        },

        // ── Pricing ──
        price: {
            type: Number,
            required: true,
            min: 0,
        },
        discountPrice: {
            type: Number,
            required: false,
            min: 0,
        },

        // ── Inventory ──
        countInStock: {
            type: Number,
            required: true,
            default: 0,
            min: 0,
        },
        sku: {
            type: String,
            required: true,
            unique: true,
        },

        // ── Categorization ──
        category: {
            type: String,
            required: true,
        },
        brand: {
            type: String,
            required: false,
        },
        collections: {
            type: String,
            required: true,
        },

        // ── Variants ──
        sizes: {
            type: [String],
            required: true,
            enum: ["XS", "S", "M", "L", "XL", "XXL"],
        },
        colors: {
            type: [String],
            required: true,
        },
        gender: {
            type: String,
            enum: ["Men", "Women", "Unisex"],
            required: false,
        },
        material: {
            type: String,
            required: false,
        },

        // ── Media ──
        images: [
            {
                url: {
                    type: String,
                    required: true,
                },
                altText: {
                    type: String,
                    required: false,
                },
            },
        ],

        // ── Reviews & Ratings ──
        rating: {
            type: Number,
            default: 0,
            min: 0,
            max: 5,
        },
        numReviews: {
            type: Number,
            default: 0,
            min: 0,
        },

        // ── Tags & SEO ──
        tags: {
            type: [String],
            required: false,
        },
        metaTitle: {
            type: String,
            required: false,
        },
        metaDescription: {
            type: String,
            required: false,
        },
        metaKeywords: {
            type: String,
            required: false,
        },

        // ── Physical Dimensions ──
        dimensions: {
            length: {
                type: Number,
                required: false,
            },
            width: {
                type: Number,
                required: false,
            },
            height: {
                type: Number,
                required: false,
            },
        },

        // ── Ownership ──
        user: {
            type: mongoose.Schema.Types.ObjectId,
            ref: "User",
            required: true,
        },

        // ── Visibility ──
        isFeatured: {
            type: Boolean,
            default: false,
        },
        isPublished: {
            type: Boolean,
            default: false,
        },
    },
    {
        timestamps: true,
    }
);

module.exports = mongoose.model("Product", productSchema);
